Download the Windows x64 EXE, Apple Silicon (`mac-arm64`) DMG, or Intel (`mac-x64`) DMG. Quit the previous desktop app before replacing it. Existing account and encrypted capture data paths are retained.

The game overlay is off by default. Enable it in Account menu → Desktop settings → Game overlay or the tray menu. `Ctrl/Cmd+Shift+O` toggles visibility, `Ctrl/Cmd+Shift+I` enables interaction, and Escape restores click-through. Idle opacity is adjustable; hover/interaction makes the panel opaque, and import notices briefly reveal it.

These are beta installers for native testing. Windows has no verified publisher signature. Mac apps have integrity signatures but are not Developer ID–signed or notarized. Work-managed devices may block them. Do not disable system protections to install them.

Automated packaging checks and installer checksums do not establish real PTCGL, fullscreen, or native first-launch acceptance. Report the OS, app version, and observed behavior when testing.
